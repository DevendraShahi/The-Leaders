# The Leaders v1.4.0 Release Notes

Release date: February 9, 2026

## Highlights
- Introduced full bilingual content infrastructure (English/Nepali) across major public pages and election flows.
- Upgraded admin content operations with stronger controls, richer workflows, and clearer activity tracking.
- Redesigned homepage hero and election experience for cleaner structure, stronger typography, and improved interaction quality.
- Improved election ingestion and rollback capabilities for safer high-volume updates.

## Major Changes

### 1) Localization and Language Experience
- Added/expanded centralized locale content with bilingual rendering support.
- Improved language switching behavior across navbar, reader experiences, and key page sections.
- Improved Nepali rendering consistency (labels, headings, card text, and date presentation handling).

### 2) Election Content and Ingestion
- Improved `/api/admin/perplexity-ingest` validation, normalization, and localized merge handling.
- Added ingest rollback endpoint and snapshot model support for safer corrections.
- Improved election content display clients for analyses, daily briefs, fact checks, map, parties, PR candidates, and profiles.

### 3) Admin Platform Upgrades
- Added access matrix setup page for permission-oriented admin management.
- Improved content table operations:
  - inline visibility/actions
  - status handling improvements
  - pagination/count fixes
  - better consistency for draft vs published rendering logic
- Added confirmation dialog patterns for destructive actions.
- Improved activity feed detail (username-attribution behavior integrated in recent work).

### 4) Homepage and UX Refinements
- Reworked hero section with:
  - GSAP motion orchestration
  - Nepal-time election countdown
  - theme-adaptive WebGL background layer
  - cleaner CTA hierarchy and spacing rhythm
- Added mobile navbar language toggle.
- Refined election section pacing and visual continuity below hero.

### 5) Frontend and Structural Cleanup
- Removed legacy/unused cursor component path and loader demo page.
- Introduced cleaner client wrappers where needed (`*Client.tsx`) for election routes.
- Continued typography and layout consistency improvements across homepage and election pages.

## Developer Notes
- Build/runtime fixes include stricter type-safe parsing in ingest pipelines.
- Release includes broad UI + API + model changes; downstream environments should run a full smoke test after deploy.

## Suggested Post-Release Checks
- Verify language switch persistence and per-page rendering in both EN/NE.
- Verify ingest import + rollback flows with sample bilingual payloads.
- Verify admin role/access matrix behavior for Super Admin vs Admin.
- Verify draft/published visibility on public election/article surfaces.
- Verify hero performance and animation behavior on mobile + desktop, dark + light themes.
