# The Leaders v1.8.0 Release Notes

Release date: March 1, 2026

## Executive Summary
v1.8.0 focuses on Election 2026 experience quality and data trust:
- stronger verified election datasets (2074 + corrected 2079 rows)
- cleaner and more informative chart UX
- better bilingual rendering
- improved long-form content readability on mobile
- stronger trend ingestion infrastructure (API + normalization pipeline)

## Highlights
- Official Candidate Snapshot rebuilt into a metric-first intelligence section.
- 2022 election pie chart restored and upgraded; 2074 comparison supported.
- Voter Demographics updated with election-cycle voter-roll data.
- Provincial Breakdown redesigned with meaningful tooltips and bilingual labels.
- Daily brief and analysis markdown pages now use balanced typography and mobile-optimized spacing.
- Trending-topic backend is now richer and source-aware; dashboard placement is temporarily removed.

## UI/UX Changes

### 1) Election Dashboard Composition
- File: `src/app/election-2026/components/AnalyticsDashboard.tsx`
- Updated section orchestration for a cleaner narrative flow.
- Trending Topics block removed from the dashboard surface to reduce noise and avoid mixed-signal presentation.

### 2) Official Candidate Snapshot Redesign
- Files:
  - `src/app/election-2026/snapshot/SnapshotFactsClient.tsx`
  - `src/app/election-2026/snapshot/page.tsx`
- Redesigned from simple cards to a structured intelligence module:
  - candidate universe size
  - party footprint
  - ballot structure ratios
  - territory coverage
  - representation metrics
- Added improved bilingual text handling and cleaner visual hierarchy.

### 3) Pie Chart and Election Result UX
- File: `src/app/election-2026/components/charts/ImpressivePieChart.tsx`
- Reintroduced and improved multi-election pie analytics:
  - better seat aggregation logic
  - PR vote + PR seat presentation consistency
  - localized party names
  - improved mobile interaction handling
  - clearer grouped small-party behavior

### 4) Provincial Breakdown UX
- File: `src/app/election-2026/components/charts/RegionalBreakdownChart.tsx`
- Added bilingual province/party labels and stronger chart context.
- Introduced explanatory hint system with improved layering and placement.
- Added pinned province detail card and clearer seat-gap/PR-gap interpretation.

### 5) Voter Demographics and Turnout Presentation
- Files:
  - `src/app/election-2026/components/charts/TabbedDemographics.tsx`
  - `src/app/election-2026/components/charts/TurnoutTrendChart.tsx`
- Voter-focused sections now reflect verified voter-roll cycle data.
- Candidate demographics section kept behind a local toggle (currently hidden by design).
- Summary metric cards updated for readability and trust.

### 6) Long-Form Reading Experience
- Files:
  - `src/app/election-2026/daily-brief/[slug]/DailyBriefDetailClient.tsx`
  - `src/app/election-2026/analyses/[slug]/AnalysisDetailClient.tsx`
- Markdown display improved with:
  - normalized heading parsing

  - cleaner list rendering

  - mobile-responsive spacing and wrapping

## Data and Logic Updates

### 1) Analytics Data Model Expansion
- File: `src/lib/analytics-data.ts`
- Added:
  - `electionResults2074`
  - richer `PartyProjection` fields (`prVotePercentage`, `prSeats`, `fptpSeats`)
  - richer `RegionalData` fields for seat/PR comparison
  - richer `TrendingTopic` metadata (references, verification, momentum, etc.)
  - voter cycle structure for demographics (`voterRollByCycle`)

### 2) Election Result Correction
- File: `src/data/Districts/nepal_election_results_2022.json`
- Corrected district winner party row:
  - `Gyan Bahadur Shahi` mapped to `Rastriya Prajatantra Party`.

### 3) Trending Signal Aggregation
- Files:
  - `src/lib/api/news-service.ts`
  - `src/app/api/election/trending-topics/route.ts`
  - `src/app/election-2026/components/TrendingTopicsSection.tsx`
- Introduced richer trend normalization with:
  - source metadata
  - confidence/verification shape
  - category and momentum enrichment
  - localized summary fallbacks
- Added API endpoint contract for periodic trend fetch.

## Backend/API Notes
- New route: `GET /api/election/trending-topics`
- Response includes:
  - `topics`
  - `updatedAt`
  - `mode` (`verified-live` or fallback mode)
- Trend ingestion pipeline now supports timeout-aware and source-aware aggregation paths for robustness.
